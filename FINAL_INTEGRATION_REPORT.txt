## 🚀 COMPLETE BUTTON CONNECTION MAP

FRONTEND ACTION → BACKEND ENDPOINT → DATABASE

1. Initialize Button
   Admin.jsx → teamAPI.initializeAllTeams()
   → POST /api/admin/initialize
   → MongoDB: Insert 63 teams with score 0

2. Add New Team
   Admin.jsx → teamAPI.createTeam()
   → POST /api/admin
   → MongoDB: Insert new team

3. Update Score (Direct Input)
   Admin.jsx → teamAPI.updateTeam()
   → PUT /api/admin/:id
   → MongoDB: Update team data

4. +1 / -1 Buttons
   Admin.jsx → teamAPI.updateTeam()
   → PUT /api/admin/:id
   → MongoDB: Increment/Decrement score

5. Delete Team
   Admin.jsx → teamAPI.deleteTeam()
   → DELETE /api/admin/:id
   → MongoDB: Remove team

6. Apply Bulk Score
   Admin.jsx → teamAPI.updateTeam() (loop)
   → PUT /api/admin/:id (multiple)
   → MongoDB: Update all teams

7. Clear All Scores
   Admin.jsx → teamAPI.resetAllScores()
   → PATCH /api/admin/reset-all
   → MongoDB: Set all scores to 0

8. Search/Filter
   Admin.jsx (local)
   → Filters teams array in real-time
   → No backend call needed

9. Import Data
   Admin.jsx → teamAPI.updateTeam() (loop)
   → PUT /api/admin/:id (multiple)
   → MongoDB: Update from file

10. Home Page Update
    Home.jsx → teamAPI.getAllTeams()
    → GET /api/admin
    → MongoDB: Fetch all teams
    → Display in real-time

## 🎯 HOW TO USE

1. START SERVERS
   - Backend: cd backend && npm start
   - Frontend: cd vite-project && npm run dev

2. INITIALIZE TEAMS
   - Login to Admin panel (http://localhost:5173/admin)
   - Click "Initialize" button
   - All 63 teams loaded from teams.json into MongoDB

3. MANAGE SCORES
   - Type score or use +1/-1 buttons
   - Changes sync to database immediately
   - Home page updates in real-time

4. VIEW LEADERBOARD
   - Open Home page (http://localhost:5173/)
   - See live rankings from database
   - Auto-updates with admin changes
